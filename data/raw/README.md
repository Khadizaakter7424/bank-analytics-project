# Raw data

Download **Churn_Modelling.csv** from Kaggle (search for "Bank Customer Churn" / "Churn Modelling")
and place it in this folder. Check the licence on the dataset page before re-sharing the file.

The file is ignored by git (see `.gitignore`), so only this note is uploaded.

Expected columns:
`RowNumber, CustomerId, Surname, CreditScore, Geography, Gender, Age, Tenure, Balance,
NumOfProducts, HasCrCard, IsActiveMember, EstimatedSalary, Exited`
